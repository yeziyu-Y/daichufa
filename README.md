# 待出发 · 携程行程 Tab 创新方案

> 把「想去」存进来，等一个合适的时机。

一个 AI Native 的旅行产品方案：在携程「行程」Tab 新增一个"活的"愿望单——
用户用一句话 / 截图 / 链接许愿，AI 每天盯价格、算时机，成熟了提醒一键成行，回来自动归档成旅行资产。

## 页面

| 页面 | 说明 |
|---|---|
| [`index.html`](./index.html) | 方案首页：一句话介绍、产品洞察、四步闭环、核心机制、V1.0 上线计划与验证门槛 |
| [`proposal.html`](./proposal.html) | 完整方案（含可交互 Demo 嵌入）：需求、机制、落地保障、指标口径、迭代路线 |
| [`demo/index.html`](./demo/index.html) | 高保真可交互原型：许愿 → 解析 → 时机分 → Push → 一键成行 → 归档 |
| [`待出发方案文档.md`](./待出发方案文档.md) | 方案 Markdown 源文档 |

## 本地预览

```bash
python -m http.server 8848
# 打开 http://localhost:8848/
```

或直接双击 `index.html`。
